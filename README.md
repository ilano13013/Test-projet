# Les Curieux — Écran de connexion animé

Un écran de connexion où trois petites silhouettes réagissent à ce que vous faites :

- **Au repos** : elles respirent tranquillement derrière la carte.
- **Champ e-mail** : elles se penchent, sourcils levés, et leurs yeux suivent le texte au fil de la frappe.
- **Champ mot de passe (masqué)** : elles se rapprochent, très curieuses, les yeux plissés pour essayer de deviner.
- **Mot de passe visible** (bouton œil) : elles détournent le regard — une se couvre les yeux, une se retourne complètement, la troisième regarde le plafond en sifflotant.

## Utilisation

Aucune dépendance : ouvrez simplement `index.html` dans un navigateur.

```bash
open index.html        # macOS
xdg-open index.html    # Linux
```

Tout est contenu dans un seul fichier (HTML + CSS + JavaScript vanilla, SVG inline pour les silhouettes).
